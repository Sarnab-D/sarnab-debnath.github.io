Sarnab Debnath — Developer Portfolio

A responsive personal portfolio built with semantic HTML, modern CSS, and vanilla JavaScript. The project presents my background as a Computer Science and Engineering student, my web-development learning journey, and selected practice projects.


About the project

This portfolio was created to strengthen my frontend fundamentals without relying on a framework or build tool. I focused on writing readable HTML, organizing a reusable CSS design system, and adding small JavaScript interactions that improve navigation and discovery.

Features

•
Responsive layout for desktop, tablet, and mobile screens

•
Dark and light theme switching with preference persistence through localStorage

•
Terminal-style hero introduction with a typing animation

•
Mobile navigation menu with accessible expanded-state updates

•
Project filtering generated from each project's technology tags

•
Scroll progress indicator and back-to-top control

•
Active navigation-tab feedback while scrolling

•
Contact form interaction with a clear front-end-only status message

•
Reduced-motion support through prefers-reduced-motion

•
Keyboard-visible focus styles and semantic navigation landmarks

Technology stack

•

Project structure

Plain Text

Run locally

No build step is required.

Bash


git clone https://github.com/Sarnab-D/sarnab-debnath.github.io.git
cd sarnab-debnath.github.io



Open index.html in a browser, or start a simple local server:

Bash


python3 -m http.server 8000



Then visit http://localhost:8000.

Development notes

The contact form currently demonstrates front-end validation and status feedback only. It does not send email until it is connected to a form service or backend endpoint. Project demo and source links should point to real destinations instead of placeholder # links.

What I learned

This project helped me practice responsive layout design, DOM manipulation, event handling, browser APIs, progressive enhancement, accessible interaction states, and organizing a small frontend codebase without a framework.
